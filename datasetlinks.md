CADET — Dataset Links
This file lists the datasets used for CADET (Compression-Aware Explainable Bimodal Deepfake Detection for Image and Video Analysis).
Image Datasets
1. 140K Real and Fake Faces
   https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces
2. Celeb-DF v2 Image Dataset
   https://www.kaggle.com/datasets/pranabr0y/celebdf-v2image-dataset
3. FaceForensics++ C23 Extracted Faces 100K
   https://www.kaggle.com/datasets/gradientvoyager/faceforensics-c23-extracted-faces-100k
Video Datasets
1. FaceForensics++ C23
   https://www.kaggle.com/datasets/xdxd003/ff-c23
2. Celeb-DF v2
   https://www.kaggle.com/datasets/reubensuju/celeb-df-v2
3. UADFV Dataset
   https://www.kaggle.com/datasets/adityakeshri9234/uadfv-dataset
Download Notes
- Open each Kaggle link and sign in to your Kaggle account if required.
- Read the dataset description, license, and usage conditions before downloading.
- The datasets are not stored in this GitHub repository because of their size and applicable access or licensing conditions.
- Dataset availability and download requirements are controlled by the respective dataset owners.
Important
Check the project notebooks and preprocessing scripts for the exact dataset versions, splits, and preprocessing steps used in each experiment.
